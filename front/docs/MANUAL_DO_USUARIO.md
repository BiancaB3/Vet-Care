# VetCare — Manual do Usuário

Bem-vindo ao VetCare! Este manual explica como utilizar o sistema de gestão para clínicas veterinárias, desde o acesso até o uso das principais funcionalidades.

---

## 1. Acesso ao sistema

- **Login:**
  - Acesse a página inicial e clique em "Acessar Sistema".
  - Informe seu e-mail e senha cadastrados.
  - Caso esqueça a senha, entre em contato com o administrador.

---

## 2. Funcionalidades principais

### 2.1. Cadastro de tutores
- No menu lateral, clique em "Tutores".
- Clique em "Novo Tutor" e preencha os dados do responsável pelo pet.
- Salve para adicionar o tutor à sua lista.

### 2.2. Cadastro de pets
- Acesse a seção "Pets".
- Clique em "Novo Pet" e preencha as informações do animal.
- Relacione o pet a um tutor já cadastrado.
- Salve para adicionar o pet.

### 2.3. Agendamento de consultas
- Vá para "Agendamentos".
- Clique em "Nova Consulta".
- Escolha o tutor e o pet, defina data/hora, diagnóstico e prescrições.
- Salve para registrar a consulta.

### 2.4. Finalizar consulta
- Após realizar uma consulta, clique em "Finalizar".
- O sistema simula o envio de um resumo/receita por e-mail ao tutor.

---

## 3. Navegação e dicas

- Use o menu lateral para acessar rapidamente Tutores, Pets, Agendamentos e Sair.
- Os dados são salvos localmente e visíveis apenas para o veterinário logado.
- Para sair, clique em "Logout" no menu.

---

## 4. Suporte

Em caso de dúvidas ou problemas, procure o responsável técnico ou o desenvolvedor do sistema.
